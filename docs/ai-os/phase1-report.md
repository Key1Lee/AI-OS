# AI-OS Phase 1 report — 2026-10-04

Local implementation and policy contracts are implemented and tested. Operational provider readiness remains unproven. This report separates the shared upgrade from the [pre-upgrade architecture audit](../audits/workspace-architecture-2026-10-04.md) and [Semantic & Metrics build](<../../projects/Semantic & Metrics System/docs/phase1-report.md>).

1. **Existing architecture:** `ModelRouter`, `AIOSRuntime`, local llama.cpp/Qwen, optional Responses/Messages transports, schema validation, cloud ledger and metadata audit already existed. Toptal duplicated interviewer/evaluator clients and selection/failure handling. Other inspected projects had no independent vendor clients. No universal workflow scheduler was found or added.
2. **Changes:** Extended the existing layer with neutral intelligence/decision contracts, bounded workflow tool execution, native OpenAI/Claude proposals, official Jev SDK transport, readiness evidence, call attribution, hard model/privacy/residency/cost/context/fallback limits, safe project aliases and migrated Toptal clients. Business prompts, state, tests, exercise gates and rubrics remain project-owned. Root packaging supports editable installation in the server interpreter. The registry records the actual Toptal consumer.
3. **Qwen:** SUPPORTED and CONFIGURED locally: discovered Qwen3-4B-Q4_K_M GGUF/llama.cpp. Live loopback checks fail, so UNAVAILABLE; tested=false/available=false. Existing generation/structured-output paths retained. Local tools remain unsupported until runtime/template verification. No cloud Qwen integration was added.
4. **OpenAI:** Responses reasoning, structured output and native tool proposals supported; Toptal typed parsing/session references preserved through central transport. Shared interpreter has no SDK, model enable configuration or credential; authentication, live task and availability unproven. Toptal's native environment has the existing SDK and passes injected-client tests. Default neutral generation uses store=false; Toptal interviewer intentionally retains store=true continuation.
5. **Claude:** Messages generation/structured output/native tool proposals supported. Shared interpreter has no SDK, configured model or credential; authentication/live task/availability unproven. No Agent SDK, Managed Agents, autonomous sandbox or handoff capability is claimed.
6. **Jev:** Bounded CHOICE/SCORE/NOUL adapter uses the maintained [official TypeSafe SDK](https://docs.typesafe.ai/sdk/python). Score is a probability-weighted rubric value; Noul is yes probability without invented confidence. Shared SDK/configuration/credential absent; live decision quality, authentication and availability unproven. Injected SDK contract/failure tests pass. No prose/code generation or generative fallback.
7. **Provider capability matrix:** Qwen supports local generation/structured output; OpenAI/Claude add bounded native proposals; Jev supplies typed decisions only. All require real configuration and appropriate policy. Adapter support is independent from live account/model support. See [routing matrix](provider-routing.md).
8. **System-to-capability matrix:** Modeling may request SQL help; Orchestration explanation; Quality bounded fuzzy assessment; Observability incident reasoning/classification; Semantic governed metric explanation; AE/FDE tutoring/stakeholder simulation; Toptal questions/evaluation. Python and local JSON process interfaces exist for all. Actual migrated applications are Toptal provider consumers; other adoption is explicitly prospective. See [ownership matrix](intelligence-plane.md).
9. **Routing:** Local-first general reasoning; task-specific OpenAI/Claude preferences only when allowed. Explicit provider/model pins, permitted providers, privacy/offline/local residency, capability/context limits and budgets filter every candidate. Unknown strict capacity/capability rejects. Latency is an inspectable preference, not an invented SLA. High declared cost requires trusted approval. Fallback never weakens constraints.
10. **Jev decision policy:** Deterministic truth first; hard failure DENY without a Jev call. Unresolved bounded questions use Jev only if cloud policy permits. Validate rubric/model/distribution and confidence; uncertainty/unavailability returns REVIEW. Human approval and security rights are never granted by probabilities. The synthetic +38% revenue fixture produces HIGH / DATA_ENGINEERING / risk2 / escalate0.95 and REVIEW under its stubbed policy. Live calibration is not claimed.
11. **Verification hierarchy:** Deterministic invariant, schema, observable state, optional bounded judgment, independent generative evaluator where necessary, human review for risk/uncertainty. Unverified text is proposed; verified requires a workflow callback. Tool mutation requires authorization, idempotency key and post-state check. Read tools always reobserve current state. Reused mutations recheck their verifier.
12. **Security:** Credentials and client construction live centrally in the server environment. Projects retain tool handlers and hard domain authorization. JSON cannot supply executable handlers/verifiers, deterministic verdicts, human tool grants or high-cost approval. No arbitrary shell/MCP/RAG scheduler authority was added. Metadata omits prompts/state/arguments; audit failure halts continuation. A local process contract is not an authenticated network service. Legacy omitted attribution gets generated request/run IDs and caller `py-dev`.
13. **Failure/fallback evidence:** All 119 shared policy/adapter/CLI tests pass: [final log](evidence/shared-tests-final.txt). Native Toptal/Observability regression passes 152 tests; after final provider-setting cleanup, affected Toptal tests pass 28. The registry validator passes all 10 systems. Review calls cannot reset run budgets. Session recovery reserves/traces each physical attempt; a budget of one blocks a second call. Provider failure after a mutation remains uncertain and never triggers provider replay. Fresh reads observe 700 before and 1,000 after a 300-row write. Incomplete OpenAI responses cannot execute proposed tools, and JSON callers cannot grant high-cost approval. The first broad run was blocked by nested macOS sandbox restrictions and protected log paths; temporary telemetry plus an approved outer-sandbox rerun preserved the real SQL worker and passed. [Native regression log](evidence/toptal-observability-tests-final.txt).
14. **False-success result:** Real isolated SQLite has 700 committed rows while a stub agent claims successful completion of 1,000. `COUNT(*)` fails the approved invariant: intelligence status rejected, deterministic=false, no fallback. Decision status REJECTED/DENY makes zero Jev calls. This is actual local state evidence, not a model judging its own claim.
15. **Files changed:** Shared `py_dev/{models,config,capabilities,router,runtime,runtime_config,__init__,__main__,intelligence,decisions,decision_config,provider_health,telemetry}.py`; adapters `providers/{openai,claude,jev,parsed}.py`; root `pyproject.toml`; `config/{project-aliases.toml,intelligence.env.example}`; focused tests; seven requested `docs/ai-os` guides, this report, independent report and evidence; architecture/runtime/model-router/map/registry metadata. Toptal changes are its app/config/interviewer, training/config/evaluator, launcher, requirements, example environment, README and explicit central-policy test fixtures. Semantic files remain wholly inside their separate project. Existing concurrent registry/AGENTS work was preserved.
16. **Remaining risks:** No live provider reasoning/failure calibration; cloud SDKs/configuration absent from shared interpreter; Qwen server unavailable; call ceilings are not monetary billing limits; service-instance decision run limits require one retained service per run; durable mutation idempotency and verifiers are workflow-owned. No universal sibling adoption, production rollout or learner mastery proven. Existing audit findings remain open: AE wrong output can be trusted, original Toptal HTTP boundary permits hostile requests, backfill IDs collide, Modeling's normal editable environment is stale. Shared provider tests do not conceal or repair these unrelated domain defects. All 120 sampled saved state files remain unchanged: [preservation](evidence/preservation.json).
17. **Exactly one next architectural improvement:** Fix AE Lab's trusted-publication predicate so every required deterministic modeling/quality/metric check for the same artifact and run must pass before output is marked trusted. Use the retained silent-corruption probe as acceptance evidence.
18. **Three recall questions:** Which evidence can override a model's completion claim? How is a Jev judgment different from a generative response and deterministic proof? Which constraints must remain true across provider fallback?
