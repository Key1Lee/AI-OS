# Level up

Input: recent audit findings, run traces, project friction, or concrete repeated work. If no evidence is available, request one example or inspect existing evidence first. Compare candidate improvements by impact, confidence, cost, and reversibility. Choose exactly one; a new Skill is only one possible outcome.

Output either a reviewable proposal with evidence, scope, a concrete testable acceptance check, and dependencies, or an authorized shipped improvement with the same evidence and verification. When evidence shows a symptom but not its cause, propose one diagnostic or validation step and label the cause unverified; do not promise zero future failures. Do not infer frequency from one anecdote, fabricate savings, trigger paid providers, or broaden permissions. Ask only for missing input needed to choose or implement the improvement. Stop when the evidence cannot support a specific recommendation.
