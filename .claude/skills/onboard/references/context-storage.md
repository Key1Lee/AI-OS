Use `python3 skills/onboard/scripts/save_context.py --scope global --input <confirmed-json>` for global context, or `--project <name>` for project context. The input JSON must contain `confirmed: true` and a `facts` object; it may include `source` and `confirmed_at`. The script validates project names, merges fields, and writes atomically. Global data lives under the local AI-OS data directory. Project data lives in `projects/<name>/state/context.json`. Inspect the existing record before proposing changes. Do not store API keys or passwords.
