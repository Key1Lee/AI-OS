Use `python3 skills/link/scripts/register.py --target <path-or-url> --purpose <text> [--project <name>] [--id <stable-id>] [--authority <label>] [--freshness-days N] [--related <existing-route-id>]`. Local targets must exist. External URLs are recorded without fetching by default and remain `unverified` until checked by an authorized connector. The project registry is `projects/<name>/state/sources.json`; the global registry is in the local AI-OS data directory. The registry stores routes, explicit route relationships, and evidence metadata, not source bodies.
