## Structures and conventions already present

- Modeling exposes `modeling-lab-v1`, explicit grain/key/relationship contracts, SQL transformations and golden-row checks. Raw order versions, customer IDs, product IDs, order_items, payments and returns already exist there. Its N:1 and 1:N relationships must not be flattened blindly.
- Quality exposes `data-contract-v1`, `quality-bundle-v1`, `quality-event-v1` and `quality-gate-v1`. Its semantic_meaning field is submitted metadata, not an independent authority over business meaning. UNKNOWN withholds a blocking gate.
- Observability exposes `data-map-v1` with metric/model/output nodes, provenance, edges, executions and incident observations. It owns recorded operational evidence, not approval of formulas.
- Orchestration's `contracts/execution-event.schema.json` exposes `orchestration-event-v1`: attempts, statuses, partition, timestamps and upstream state. It does not define metric recognition rules.
- AE Lab owns its warehouse, fixtures, run events and learner loop, with native subprocess adapters to five sibling systems. A new semantic project must not duplicate this orchestration or overwrite AE learner state.
- FDE already separates customer discovery from semantic contracts and hides its evidence artifacts behind its own learning policy. Its integration registry is reference-only; this project must not claim that a reference is a live connection.
- Toptal owns assessment evidence and mastery. This project will record practice and unanswered recall prompts, not confer independent mastery or update Toptal state.

## Phase 1 decision

Create an independent, stdlib-only semantic registry and bounded local evaluator over **already-modeled** authored commerce snapshots. Specify a new synthetic Finance fulfillment/Chicago contract without changing the definitions above. Consumers identify the same metric ID/version and receive the same definition fingerprint. Integrations use explicit, provenance-carrying artifact contracts; live sibling execution and production business approval remain outside Phase 1.

No code or existing business definition was changed during discovery.
