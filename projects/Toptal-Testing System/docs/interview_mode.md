# Strict SQL interview practice

The current mode offers one original SQL scenario, visible query runs,
clarification questions, assumption notes, optional elapsed time and final
hidden-case submission. Hints are denied and the request is audited without
claiming that denied help was used. Explicit solution reveal is allowed as a
learning choice and marks the attempt assisted before displaying the solution.

Clarification responses use the exercise's frozen rules. Questions that do not
match a rule point to the published contract and allow explicit assumptions;
no retroactive acceptance criterion is invented. Clarifications do not reduce
independence. Explanation quality and clarification quality are recorded but
not automatically scored in this SQL-only release.

The timer is informational. It includes wall-clock time since the draft began,
including pauses; no timing threshold causes failure. This is not a complete
mixed senior interview loop. Cross-domain rounds, model-scored communication
and requirement changes belong to Phase 5 and remain planned.
