# Competency model

Stable IDs, category, name, description, importance, prerequisites, relationships
and difficulty progression are defined in `curriculum/competencies.yaml`.
The initial executable coverage is SQL, with grain and metric correctness
cross-links. Other domain nodes are explicitly unassessed until exercises exist.

Mastery levels: 0 Unassessed, 1 Foundational Gap, 2 Developing, 3 Independent,
4 Senior Ready, 5 Strong Senior / Staff Signal. Levels are scoped to covered
competencies, not employment readiness. Confidence is a coarse evidence label
(none, limited, moderate, strong), never a probability of hiring.

Every state cites attempts, assistance, context/family, difficulty, recency,
misconceptions and unresolved gaps. The application records practice evidence
in its own database. It never overwrites the project's four canonical records.
