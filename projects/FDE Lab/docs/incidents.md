# Local incident practice

```text
Impact → timeline → containment → causal evidence → recovery
 → verification → prevention
```

After reviewed evaluation, `fde break` introduces a separate faulty branch and a synthetic operations interruption. It preserves your original repair. Ask for evidence rather than guessing the cause from the visible symptom. Record diagnosis with `fde debug`, then execute the incident branch checks.

The incident affects only local generated data. A tutor assesses causal reasoning separately from the passing regression.
