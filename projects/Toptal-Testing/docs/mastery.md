# Reading mastery evidence

Open Competency Map and expand a row to inspect attempt links, independent
successes, contexts, highest independent difficulty, confidence, open test
patterns and recency. This is scoped practice evidence, not a hiring forecast.
The complete deterministic policy is in [scoring](scoring.md).

One independent success reaches Developing. Different original problems can
establish Independent. Senior levels also require harder exercises, cold
transfer and no unresolved mistakes. Evidence dates and due reviews show
freshness; levels do not expire automatically. Repeating a passed question
or using hints/solutions does not add independent credit. Assistance is retained
across revisions and explicit external help is recorded.

Mistake Review identifies observed failing test contracts and source attempts.
It does not infer a psychological misconception from a syntax error. A fully
correct independent exercise in a different family, testing that competency,
can close a recorded pattern; its retest link remains auditable. A later failure
reopens the pattern and lowers the current rating without deleting history.

`events` stores completion, evidence, mistakes, changes and review scheduling.
`mastery` is the current projection under policy `ae-v1`. Re-scoring history for
a new policy is a future explicit migration, never a silent rewrite.

The twelve-problem bank limits attainable evidence for some competencies.
Uncovered domains are visibly Unassessed. Library filters can override the
recommended readiness for deliberate practice; recommendation difficulty uses
independent performance and failure signals.
